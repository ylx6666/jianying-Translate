# 🎬 剪映批量字幕处理工具

> 基于 Streamlit 的剪映（JianyingPro）草稿批量处理工作流，集成视频导入、字幕 AI 优化/翻译、样式套版、音频处理等一站式功能，专为批量视频字幕制作场景设计。

## ✨ 功能概览

| 模块 | 图标 | 功能说明 |
|------|------|----------|
| 导入视频 | 📥 | 批量将 MP4/MOV 导入剪映，自动生成同名草稿（MOV 自动转码） |
| 深度处理 | ⚙️ | 静音 + 合轨 + 按字幕切视频 + 拉伸 + 套样式 + 黑底 |
| 一键重整 | 🛠️ | 去除音频 + 删旧字幕 + 注入新字幕（带黑底） |
| 字幕优化合成 | 🤖 | AI 优化中文 → 翻译英文 → 中英双语合成（支持多 API 切换） |
| 一键复制 | 📄 | 预设提示词一键复制 / 生成内嵌文字的 .bat 文件 |
