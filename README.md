## ✨ 功能模块

| 模块 | 能力 |
|------|------|
| 🤖 字幕优化合成 | ① 中文纠错润色 ② 英文翻译 ③ 中英双语合成；多模型自动降级、防半成品、配置自动记忆 |
| 📥 导入视频 | MP4/MOV 批量导入剪映专业版，自动生成同名草稿，MOV 自动转 MP4 |
| 🛠️ 一键重整 | ① 去除所有音乐/配音 ② 删除旧字幕 ③ 注入黑底新字幕，三合一 |
| ⚙️ 深度处理 | 取样优先字幕样式 + 静音 + 合轨 + 按字幕切视频 + 按音频拉伸 + 黑底，全能合一 |
| 📄 一键复制 | 提示词/任意文字一键进剪贴板，可下载内嵌文字的 bat |

## 🚀 快速开始

1. **环境**：Windows 10/11 64 位 + [Python 3.14.x 64 位](https://www.python.org/downloads/)
2. 下载并解压分发版压缩包
3. 双击 `一键翻译神器.exe`，浏览器自动打开网站
4. 在「字幕优化合成」模块填写**自己的 API Key**（OpenAI 兼容接口）即可使用

## 🧠 内置专业字幕规则

- SRT 序号行、时间轴行**原样保留**，一个字符不改，条目不增删不合并
- 中文纠错结合**铁道车辆语境**（转向架 / 车钩 / 制动机 / 轮对 等术语精准修正）
- 英文翻译时数字/型号自动转英文读法：`1998 → nineteen ninety-eight`、`C70 → C seventy`、`3号 → No. 3`

## 🛡️ 可靠性设计

- **多模型降级**：模型额度耗尽/鉴权失败自动拉黑并切换下一个模型
- **防半成品**：任务中断自动清理已生成的不完整文件
- **原子写入**：SRT 先写临时文件再替换，杜绝损坏
- **草稿自动备份**：任何剪映草稿操作前自动备份 `.bak_*`，可回滚
