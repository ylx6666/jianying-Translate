# 一键翻译神器

自己用的一个做课视频的工具。

我做铁道车辆检修课程的中英双语教学视频。语音识别出来的字幕错别字多，
再一条条翻成英文太累，就写了这个工具，把整个流程一次跑完：
中文纠错 → 翻成英文 → 合成双语字幕 → 视频导入剪映 → 注入字幕 → 后期处理。

## 功能

五个小功能，按顺序用：

- 字幕优化合成：把识别的 SRT 喂进去，AI 纠错、翻译、合成上中文下英文。
  有个硬规则：数字和型号必须写成英文读法（1998 → nineteen ninety-eight，
  C70 → C seventy），时间轴一行不许动。
- 导入视频：MP4/MOV 批量导入剪映，生成同名草稿，MOV 自动转 MP4。
  需要自备一个 ffmpeg.exe 放在指定位置。
- 一键重整：去原声、删旧字幕、注入黑底新字幕，三步一次完成。
- 深度处理：静音、合轨、按字幕切视频、拉伸、套字幕样式这些麻烦事一键干完。
- 一键复制：复制提示词、文字用的小工具。

## 使用

1. Windows 64 位，提前装好 Python 3.14 64 位（别的版本不行，程序是按 3.14 编译的）
2. 解压后双击「一键翻译神器.exe」，浏览器会自动打开
3. API Key 自备（OpenAI 兼容接口都行），在页面上填好就能用
